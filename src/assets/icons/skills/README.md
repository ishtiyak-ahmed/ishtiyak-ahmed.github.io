# Toolkit icons

Nine SVGs are copied from the official [Devicon repository](https://github.com/devicons/devicon), pinned to the revision recorded in `sources.json`. Source URLs for each unchanged SVG are recorded there. The included `LICENSE.devicon` retains the MIT notice; `public/third-party/DEVICON-LICENSE.txt` also ships that notice with production builds. Logos identify technologies; ownership/trademark rules remain with the respective owners, as explained by [Devicon](https://devicon.dev/). No full icon font or new dependency is installed.

GitHub and Vercel use a monochrome CSS treatment on dark surfaces. SQL, Power BI, DAX, Power Query, Tableau, and the four engineering practices use explicitly neutral Lucide symbols. Power BI retains a restrained yellow accent; these symbols are not claimed to be official brand artwork. Official Power BI/Tableau assets were unavailable in the chosen Devicon source, so no speculative logos were added.
